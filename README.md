# 掌宿 · PalmHost

> **掌心即机房。** 把一台闲置安卓手机变成 7×24 在线的 AI 机器人宿主。

一个给 AI 智能体用的 skill：装上之后，你的智能体就能通过 adb 接管一台安卓手机，在机内搭好
**Termux + proot Ubuntu + Linux QQ + NapCat + bot** 的完整链路，并做到开机自启、断线自愈、免扫码登录。

## 装

```bash
npx skills add siyuchen294-glitch/palmhost
```

或下载 Release 里的 `palmhost-v1.0.0.zip`，把 `palmhost/` 整个放进 `.agents/skills/`。

## 开工前你要准备

| # | 要准备 | 说明 |
| --- | --- | --- |
| 1 | 闲置安卓手机 | Android 8+，可用存储 ≥ 6G |
| 2 | 数据线 | **能传数据**，不是纯充电线 |
| 3 | 足功率充电器 | 长期插电 |
| 4 | 一个 QQ 号 | 并接受封号风险 |
| 5 | LLM API key | OpenAI 兼容格式（DeepSeek / 通义 / Moonshot 等） |
| 6 | 一台电脑 | Windows / macOS / Linux，装 adb |

## 你只需要动手机 5 次，剩下的都交给智能体

| # | 什么时候 | 你要做什么 | 耗时 |
| --- | --- | --- | --- |
| 1 | 开头 | 打开 USB 调试，插线后点「允许 USB 调试」 | 2 分钟 |
| 2 | 装完 Termux | 手动打开一次 Termux 完成初始化 | 30 秒 |
| 3 | 装环境时 | 关电池优化、加自启动白名单、开「充电时保持唤醒」 | 3 分钟 |
| 4 | QQ 首次启动 | 扫码登录（唯一一次） | 1 分钟 |
| 5 | 验收 | 锁屏 5 分钟后发条消息确认能回 | 6 分钟 |

**这 5 次做完，手机就可以扔一边挂机了。**

> 第 3 步是「能不能息屏活着」的唯一决定因素，必须卡在装完 Termux 之后做——否则系统里找不到这些设置项。

## 分工

| 环节 | 谁做 |
| --- | --- |
| 环境自检、adb 连接、装 APK、配 proot | 智能体 |
| 装 QQ / NapCat / 配 OneBot | 智能体 |
| 部署守护脚本、验收、排障 | 智能体 |
| 上面那 5 个节点 | **你** |

## 这个方案的价值边界

手机方案唯一的价值是：**7×24 在线，且不占你的电脑**。
如果只是想在电脑上偶尔聊聊，不需要这个 skill。

## 风险（请认真读）

个人 QQ 号运行协议侧机器人**违反 QQ 用户协议，存在封号风险**。
本 skill 只能降低概率，不能消除。请仅在知情前提下自用，不要用于群发、加好友引流等用途。
