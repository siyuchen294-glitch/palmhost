# 掌宿 · PalmHost

> **掌心即机房。** 把一台闲置安卓手机变成 7×24 在线的 AI 机器人宿主。

一个给 AI 智能体用的 skill：装上之后，你的智能体就能通过 adb 接管一台安卓手机，在机内搭好
**Termux + proot Ubuntu + Linux QQ + NapCat + bot** 的完整链路，并做到开机自启、断线自愈、免扫码登录。

## 装

```bash
npx skills add <你的 GitHub 用户名>/palmhost
```

或手动：把本目录整个拷到 `.agents/skills/palmhost/`（项目级）或全局 skills 目录。

## 它能替你做什么

| 环节 | 谁做 |
| --- | --- |
| 判断环境是否可行、风险交底 | 智能体 |
| adb 连接、装 APK、配 proot | 智能体 |
| 装 QQ / NapCat / 配 OneBot | 智能体 |
| 扫码登录 | **你**（唯一的人工环节） |
| 系统电池/自启动设置 | **你**（少数几步点击） |
| 部署守护脚本、验收 7 项 | 智能体 |
| 排障 | 智能体 |

## 这个方案的价值边界

手机方案唯一的价值是：**7×24 在线，且不占你的电脑**。

如果只是想在电脑上偶尔聊聊，不需要这个 skill——用网页或客户端更省事。

## 风险（请认真读）

个人 QQ 号运行协议侧机器人**违反 QQ 用户协议，存在封号风险**。
本 skill 只能降低概率，不能消除。请仅在知情前提下自用，不要用于群发、加好友引流等用途。
